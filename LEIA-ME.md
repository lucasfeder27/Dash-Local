# Dash Local — painel de investimentos sem senha e sem banco

Cada pessoa abre o link e usa. Os dados ficam só no navegador dela (nada vai para servidor).

## Publicar (uma vez só, grátis)
1. Crie uma pasta no GitHub com estes arquivos (index.html e a pasta api).
2. Na Vercel: Add New > Project > escolha o repositório > Deploy.
3. Não precisa de variáveis nem de Redis.
4. Se a Vercel pedir login ao abrir o link: Settings > Deployment Protection > desligue "Vercel Authentication".

## Para quem usa
- Abra o link, escolha nome, carteira (opcional) e as abas que quer.
- iPhone: Compartilhar > Adicionar à Tela de Início (evita o Safari apagar os dados).
- Faça backup de vez em quando: Visão Geral > Configurações avançadas > Backup.
- Outro aparelho: na tela inicial use "Já tenho um backup: importar".
